# Contributing / المساهمة

Thank you for improving Folder Sync. Keep changes focused, safe, and cross-platform.

1. Create a focused branch.
2. Install development tools: `python -m pip install -e . pytest ruff`.
3. Add or update tests for behavioral changes.
4. Run `ruff check src tests` and `pytest -q`.
5. Document user-visible behavior in both English and Arabic README sections when relevant.
6. Never commit real personal files, credentials, tokens, or sensitive manifests.

For destructive behavior, preview-first semantics and explicit opt-in are required. Pull requests should explain safety implications.

شكرًا لمساهمتك. اجعل التغييرات محددة وآمنة ومتوافقة مع الأنظمة الرئيسية، وأضف اختبارات لأي تغيير سلوكي. أي ميزة قد تحذف أو تستبدل بيانات يجب أن تبقى قائمة على المعاينة والموافقة الصريحة.
